Use ao abrir uma conversa nova quando não souber em que pé está o projeto.

1. Leia `ESTADO.md` e `LOG.md`.
2. Rode `python3 scripts/gate.py` (e `--figuras` se já houver seções).
3. **Confira se `ESTADO.md` bate com a realidade dos arquivos** — seções que existem,
   contagens, figuras. Se divergir, corrija `ESTADO.md` e avise o que estava errado.
4. Reporte de forma curta:
   - onde o projeto está (etapa, seções prontas, páginas estimadas de 20)
   - o que está bloqueando
   - **a próxima ação**, com o comando exato a rodar
   - o que depende de decisão ou material do autor

Não comece a escrever nada. Este comando só orienta.
